# Rev.AI 🤖

> AI-powered guest review intelligence for hospitality businesses — built with React, Express, and MongoDB Atlas.

Rev.AI instantly classifies guest reviews by **sentiment** (positive / neutral / negative), detects the primary **theme** (food, host, location, cleanliness, value, experience), and generates a professional **management response** — all persisted to MongoDB so your insights survive server restarts.

---

## 🗄️ Database Choice

**MongoDB Atlas (Free Tier)** was chosen for this project for the following reasons:

| Reason | Detail |
|---|---|
| **Document model** | Each review is a self-contained JSON document — no joins needed |
| **Schema flexibility** | Easy to add new fields (e.g. AI scores) without migrations |
| **Atlas free tier** | 512MB hosted cluster — zero infrastructure cost for this project |
| **Mongoose ODM** | Provides schema validation, indexing, and clean query API |
| **Text search built-in** | Native `$text` index powers keyword search across review fields |

## 📊 Schema Diagram

![Rev.AI MongoDB Schema](./W5_SchemaDiagram_TBI-26100834.png)

> **Collection:** `week5db.reviews`  
> **Indexes:** Text index on `reviewText + response + theme` | Compound index on `sentiment + theme + analyzedAt`

### Field Reference

| Field | Type | Validation | Notes |
|---|---|---|---|
| `_id` | ObjectId | Auto | Primary key, generated by MongoDB |
| `reviewText` | String | Required, 5–5000 chars | The raw guest review |
| `sentiment` | String | Enum: positive/neutral/negative | Classified by AI engine |
| `theme` | String | Enum: food/host/location/cleanliness/value/experience | Detected topic |
| `themeIcon` | String | — | Emoji icon mapped from theme |
| `response` | String | Required | AI-generated management response |
| `analyzedAt` | Date | Default: now | When the review was analyzed |
| `createdAt` | Date | Auto (timestamps) | Mongoose auto-field |
| `updatedAt` | Date | Auto (timestamps) | Mongoose auto-field |

## 🚀 Quick Start

### Prerequisites

- **Node.js** v18+ — [Download](https://nodejs.org)
- **MongoDB Atlas** account (free tier) — [Sign up](https://www.mongodb.com/cloud/atlas)

---

### Step 1 — Clone the Repository

```bash
git clone https://github.com/your-username/rev-ai.git
cd rev-ai
```

---

### Step 2 — Set Up the Database (MongoDB Atlas)

1. Go to **[cloud.mongodb.com](https://cloud.mongodb.com)** and sign in
2. Click **Build a Database** → choose **Free (M0 Sandbox)**
3. Choose a cloud provider & region → click **Create**
4. **Security → Database Access** → Add a new database user:
   - Username: `youruser`
   - Password: `YourStrongPassword123` *(use only letters & numbers — avoids URL encoding issues)*
   - Role: **Atlas Admin**
5. **Security → Network Access** → Click **Add IP Address** → **Allow Access from Anywhere** (`0.0.0.0/0`)
6. **Database → Connect → Connect your application** → Driver: Node.js → copy the URI

---

### Step 3 — Configure Environment Variables

```bash
cd server
cp .env.example .env
```

Open `server/.env` and fill in your values:

```env
PORT=5000
NODE_ENV=development
MONGO_URI=mongodb+srv://youruser:YourStrongPassword123@cluster0.xxxxx.mongodb.net/week5db?retryWrites=true&w=majority
GEMINI_API_KEY=your_gemini_api_key_here
```

> ⚠️ **Never commit `.env`** — it contains your database credentials. Only `.env.example` is committed.

---

### Step 4 — Install Dependencies

```bash
# Backend
cd server && npm install

# Frontend
cd ../client && npm install
```

---

### Step 5 — Run the Application

**Terminal 1 — Backend:**
```bash
cd server
node server.js
```

You should see:
```
✅  MongoDB connected: cluster0.xxxxx.mongodb.net
🚀  Rev.AI server running on  http://localhost:5000
```

**Terminal 2 — Frontend:**
```bash
cd client
npm run dev
```

Open **[http://localhost:5173](http://localhost:5173)**

## 🌐 API Documentation

Base URL: `http://localhost:5000/api`

### All 6+ Endpoints (MongoDB-powered)

| Method | Endpoint | Description | Status Codes |
|---|---|---|---|
| `GET` | `/api/health` | Server + DB health check | 200 |
| `POST` | `/api/reviews/analyze` | **Create** — Analyze & save reviews to MongoDB | 201, 400 |
| `GET` | `/api/reviews` | **Read** — Get all reviews (paginated) | 200 |
| `GET` | `/api/reviews/stats` | **Read** — Aggregated dashboard statistics | 200 |
| `GET` | `/api/reviews/search` | **Read** — Full-text search + filter | 200, 400 |
| `GET` | `/api/reviews/filter` | **Read** — Filter by sentiment/theme | 200, 400 |
| `GET` | `/api/reviews/:id` | **Read** — Get single review by ObjectId | 200, 400, 404 |
| `DELETE` | `/api/reviews/:id` | **Delete** — Remove one review | 204, 404 |
| `DELETE` | `/api/reviews` | **Delete** — Clear all history | 200 |
